Entity Rule

Utilizes the <EntityRule> component. EntityRule enables the assessment of the existing table. This is beneficial when you establish customized actions that apply to the table template rather than particular tables. For instance, you could like to include a ribbon component in all tables, except a few specific tables. Defining the custom action for a table pattern that applies to all tables and using an EntityRule to exclude specific tables is a more convenient approach.

The EntityRule has an additional argument called "context," which may be used to indicate whether the table is being shown in the form or as a list (HomePageGrid).
